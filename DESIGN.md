# Artkin Carreon Portfolio Design Contract

Source reference: stitch_ai_systems_laboratory/DESIGN.md and screen.png.

## Preserved from Stitch

- Fixed 280px technical sidebar on desktop.
- Warm engineering-paper canvas and 16px dot grid.
- Geist and Geist Mono typography.
- Indigo system accents.
- Square, border-defined modules with no decorative shadows.
- Numbered, monospace section labels.
- Generous editorial spacing and a maximum 1100px canvas.
- Mobile transformation from fixed sidebar to a 64px top bar and drawer.

## Personalized

- Identity: ARTKIN CARREON.
- Role: AI Automation Specialist.
- Audience: small-business owners and decision-makers.
- Primary action: View my work.
- Secondary action: Discuss an automation.
- Custom workflow diagram with human approval as an explicit system node.
- Accessible dark palette alongside the warm light reference palette.
- Proof-gated projects and credentials.
- Private case-study builder and inquiry review interface.

## Intentionally removed

The Stitch sample contained fictional projects, employers, metrics, technology claims, credentials, and AI news. None were copied into the portfolio.

## Implementation overrides

- Semantic HTML and logical heading order.
- Keyboard-accessible navigation and forms.
- 44px minimum interactive controls.
- Visible focus styling.
- Reduced-motion handling.
- No hover-only information.
- No arbitrary HTML in future case-study content.
